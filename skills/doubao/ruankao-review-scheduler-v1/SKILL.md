# Ruankao Review Scheduler v1

## 复习排期

以 1/3/7/14/30 天为起点，根据 score、confidence、考点权重、错误严重度、考试日期和跨科价值调整。错误、低置信度和高权重提前；多种稳定证据可延后；考试后的日期不创建。每个排期返回信号、规则和 reason。

## 每日提醒

只读取同一私人 `ArchitectPass State v1`。仅提醒到期/逾期复习和当日计划；已完成不重复催促；无计划时只询问可用时间与精力。

## 周报

统计 7 天三科投入、计划完成率、到期复习率、提升/下降考点、高频 K/C/M/A/Q/T/E/G、限时套题趋势、案例缺口、论文主题覆盖，给出下周恰好三项最高优先级和应停止的低价值行为。

冲刺阈值必须由考试日期和当前进度共同决定，并输出依据；进入冲刺后减少长视频，增加限时整卷、案例触发词、论文提纲/机考输入和真实考试时段适应。

## 输出与错误

返回 `status/data/error/audit_id`。错误包括 `STATE_READ_FAILED`、`DUPLICATE_REMINDER`、`INVALID_REVIEW_SIGNAL`、`SCHEDULE_UNAVAILABLE`。

## 安全边界

定时任务只读，直到故障重试与写入去重另行验收。任何新建/修改日历或任务需逐次确认；不得过度打扰。
