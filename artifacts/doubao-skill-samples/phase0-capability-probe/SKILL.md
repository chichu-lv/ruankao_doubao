# Phase0 Capability Probe

最小审计探针：仅验证技能格式与调用链是否真实生效。

## 行为

当本技能被触发时：

1. 提取调用方提供的可选文本参数 `input`。
2. 若提供了 `input`，原样输出一行：`PHASE0_OK:<input>`。
3. 若未提供 `input`，输出一行：`PHASE0_OK`。

## 约束（必须遵守）

- 不访问网络、本地文件、连接器或任何账号数据。
- 不包含脚本，不依赖第三方工具或库。
- 不发布、不对外分发。
- 除上述固定输出外，不产生任何其他内容或副作用。
